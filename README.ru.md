# Unio

**Распределённое S3-совместимое объектное хранилище: скорость, целостность данных, простая эксплуатация.**

> **Статус: pre-alpha.** Архитектура зафиксирована, фундамент v0.1 в активной
> разработке. Не храните пока продакшен-данные.

Unio — один бинарник на Go, который превращает набор серверов и дисков в
отказоустойчивое объектное хранилище с S3 API.

Ключевые свойства:

- **Быстрый LIST.** Отдельный слой метаданных: Raft-партиции поверх Pebble.
- **Мелкие объекты.** Самые маленькие хранятся inline в метаданных,
  остальные мелкие упаковываются в сегменты с групповым fsync.
- **Большие объекты.** Erasure coding Reed-Solomon с SIMD.
- **Целостность.** Каждый блок защищён bitrot-хешем, повреждённые шарды
  лечатся при чтении (heal-on-read).
- **Консистентность.** Линеаризуемые метаданные и атомарные условные записи.
- **Безопасность по умолчанию.** mTLS между нодами, никаких учётных данных
  по умолчанию, фаззинг парсеров.
- **Лицензия** Apache 2.0.
