# Brand

## Logo

The Unio mark is a horseshoe-shaped **U** catching a point of data: many
drives and nodes held together as one store.

| File | Use |
|---|---|
| [`unio-mark.svg`](../assets/logo/unio-mark.svg) | Light backgrounds |
| [`unio-mark-dark.svg`](../assets/logo/unio-mark-dark.svg) | Dark backgrounds |
| [`unio-mark-mono.svg`](../assets/logo/unio-mark-mono.svg) | Single colour; inherits `currentColor` |
| [`unio-icon.svg`](../assets/logo/unio-icon.svg) | App icon, avatars, 48 px and larger |
| [`unio-icon-small.svg`](../assets/logo/unio-icon-small.svg) | Favicons and icons at 16–32 px (bolder stroke) |

Usage:

- Keep clear space around the mark of at least the dot's diameter.
- Do not rotate, outline, add effects or change the proportions.
- Use the small-size icon below 48 px; it has a heavier stroke and a larger
  dot so it stays legible.
- The wordmark is set in **Space Grotesk Bold**, lower case, tracking −3%.

## Colours

| Name | Hex | Use |
|---|---|---|
| Ink | `#0E1116` | Mark and text on light, dark backgrounds |
| Signal blue | `#2F6BFF` | Accent on light backgrounds |
| Signal blue (dark) | `#5B8CFF` | Accent on dark backgrounds |
| Paper | `#FFFFFF` | Mark on dark backgrounds |

## Name

The project is written **Unio** in prose and `unio` in code, commands and
package names. It is pronounced *YOO-nee-oh*, from Latin *unio*, "unity".
