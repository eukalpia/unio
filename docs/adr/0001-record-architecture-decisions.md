# 0001. Record architecture decisions

- Status: Accepted
- Date: 2026-10-22

## Context

Unio is a distributed storage system that many contributors will work on in
parallel. The reasoning behind decisions must survive beyond the people who
made them.

## Decision

Significant architectural decisions are recorded as ADRs in `docs/adr`.

## Consequences

- Contract and architecture changes require an ADR in the same pull request.
- Reviewers can check proposals against prior decisions.
